# CPSC4420_Project9_Team4

Team Members:
- Maxton Negreiros

This project aims to create an environment reflecting an earthquake disaster scenario using Unreal Engine. Subsequently, this environment will be used to train systems that can respond to disasters without risking human lives.


The map is laid out in a 2x2 grid, with an open staging area, high density residential block, low density residential block with damaged homes, and a high rise block with a half collapsed skyscraper. The residential block has alleyways to make access challenging, as well as a collapsed building and debris. There is a large rubble field in the major collapse zone. There are also rooftops in every block for a drone to look for potential survivors, especially in the low density block.

Some known issues include missing textures, missing models in some areas, and no landscape deformation. There are also a lot of assets that did not want to work together, so project stability could also be a concern.
